# 🖨️ MiniPrintf — Minimalist Formatted Output Printer in C

[![Language: C](https://img.shields.io/badge/Language-C-00599C.svg)](https://en.wikipedia.org/wiki/C_(programming_language))
[![Module: B-CPE-101](https://img.shields.io/badge/Epitech-B--CPE--101-blue.svg)](https://www.epitech.eu/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

> **MiniPrintf is a lightweight introductory subset of `printf(3)`**, built to explore variadic argument handling (`va_list`, `va_start`, `va_arg`, `va_end`).

---

## ⚙️ Supported Specifiers

- `%d`, `%i`: Decimal integers
- `%s`: Character strings
- `%c`: Individual ASCII characters
- `%%`: Escaped percent symbol
